# Data

- `companies.csv`: the 100 companies on the 2021 Forbes Cloud 100 and the homepage looked up for each.
- `sample_homepages_clean.csv`: a sample of the cleaned dataset, every quarter from 2019 to 2025 for the ten highest-ranked companies.
- `data_dictionary.md`: every field in both files and what it means.

The raw archived HTML and the full cleaned file stay on my laptop. The main README's Data section says why.
